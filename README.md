# VenueBook API

RESTful API сервіс для управління бронюванням та орендою конференц-залів.

##  Бізнес-завдання
Компанія надає в оренду конференц-зали. Необхідно розробити API, яке дозволить:
- Управляти залами (CRUD) та додатковими послугами.
- Шукати доступні зали на основі місткості та часу.
- Бронювати зали із розрахунком динамічної вартості (знижки вранці/ввечері, націнка в пікові години).
- Формувати звіти для бізнесу (завантаженість, дохід, популярність послуг).

##  Технічні рішення та Архітектура
Проєкт побудовано на основі **Clean Architecture** (Роберт Мартін) для забезпечення масштабованості та відмовостійкості:
- **Domain Layer:** Містить сутності (`Room`, `Booking`) та ядро бізнес-логіки розрахунку вартості (`IPricingCalculator`). Розрахунок покривається юніт-тестами.
- **Application Layer:** DTO (Data Transfer Objects), інтерфейси репозиторіїв та Use Cases.
- **Infrastructure Layer:** Реалізація доступу до даних через Entity Framework Core.
- **API Layer:** Контролери, налаштування Swagger, обробка DI.

**Стек технологій:**
- .NET 8 / C#
- Entity Framework Core (Code-First)
- PostgreSQL (Docker) / SQLite (Development)
- Swagger / OpenAPI
